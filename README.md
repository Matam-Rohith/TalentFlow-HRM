> A comprehensive Human Resource Management System for employee lifecycle management — from onboarding to payroll.

---

## ✨ Features

- 👥 **Employee Management** — Add, edit, and remove employee records with full profile details
- 🕐 **Attendance Tracking** — Log and monitor daily attendance with real-time status
- 💰 **Payroll Dashboard** — Generate payslips and track salary disbursements
- 📊 **Analytics Overview** — Visual charts for headcount, department breakdown & attendance trends
- 🔍 **Search & Filter** — Quickly find employees by name, department, or role
- 📱 **Responsive UI** — Works seamlessly on desktop and mobile

---

| Layer | Technology |

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Edge)
- No installations required

### Installation

```bash
# Clone the repository
git clone https://github.com/Matam-Rohith/TalentFlow-HRM.git

# Navigate to the project folder
cd TalentFlow-HRM

# Open in browser
open index.html
```
