# TalentFlow HRMS & ATS — Manual Test Cases

This document details the manual test suite for the TalentFlow Enterprise HRMS & ATS application. These test cases cover critical functional flows, edge conditions, user validation, and regression suites.

| Test Case ID | Test Scenario | Steps | Expected Result | Status |
|---|---|---|---|---|
| **TC-001** | Verify application load & navigation | 1. Open web application URL in browser<br>2. Check branding header and sidebar navigation links | Application loads with title "TalentFlow HRMS & ATS", default dark theme is applied, and all sidebar menus are visible | Pass |
| **TC-002** | Verify Dashboard metrics calculation | 1. Navigate to Dashboard view<br>2. Observe Total Applicants, Active Interviews, Offers Extended, and Total Hired counters | Metric counters display accurate counts matching the active candidate database and recent activity feed is populated | Pass |
| **TC-003** | Verify candidate creation with valid details | 1. Click "Add Candidate" button<br>2. Fill Full Name, Email, Phone, Role, Department, Experience, Recruiter, and Stage<br>3. Click "Save Candidate" | Modal closes, success toast appears, and new candidate is listed at top of Candidates table | Pass |
| **TC-004** | Verify mandatory field validation on candidate creation | 1. Click "Add Candidate" button<br>2. Leave required fields blank (Name, Email, Phone, Role)<br>3. Click "Save Candidate" | Form prevents submission; inline validation error messages ("Full name is required", etc.) appear under respective fields | Pass |
| **TC-005** | Verify email format validation | 1. Click "Add Candidate" button<br>2. Enter invalid email (e.g., "invalid-email-format")<br>3. Fill other valid fields<br>4. Click "Save Candidate" | Error message "Enter a valid email address." is displayed under email field; form is not submitted | Pass |
| **TC-006** | Verify candidate profile editing | 1. Open Candidates tab<br>2. Click edit (pencil) icon on any candidate row<br>3. Modify Role Applied and Experience<br>4. Click "Save Candidate" | Candidate profile updates immediately in table and detail view with modified role and experience | Pass |
| **TC-007** | Verify global candidate search | 1. Navigate to Candidates tab<br>2. Enter candidate name or role in top search bar (e.g., "Arjun")<br>3. Verify filtered table rows | Only matching candidate records are displayed; typing updates results dynamically | Pass |
| **TC-008** | Verify candidate search reset | 1. In top search bar, enter query to filter results<br>2. Click "X" clear button or erase query | Search input clears and all candidate records are restored to table | Pass |
| **TC-009** | Verify filtering by recruitment stage and department | 1. Navigate to Candidates tab<br>2. Select "Interview" in Status filter dropdown<br>3. Select "Engineering" in Department filter dropdown | Only candidates who belong to Engineering department and are in Interview stage are displayed | Pass |
| **TC-010** | Verify Kanban pipeline stage movement | 1. Navigate to Pipeline view<br>2. Drag a candidate card from "Screening" column to "Interview" column (or use detail drawer stage buttons) | Candidate moves to target stage, column counts update, and candidate history logs stage change | Pass |
| **TC-011** | Verify interview scheduling workflow | 1. Navigate to Interviews tab or click "Schedule Interview"<br>2. Select candidate, round type, future date, and time<br>3. Click "Confirm Assessment" | Modal closes, interview is scheduled, candidate status updates to "Interview", and card appears in upcoming assessments | Pass |
| **TC-012** | Verify candidate deletion with confirmation prompt | 1. In Candidates tab, click delete (trash) icon on a candidate row<br>2. Observe confirmation modal<br>3. Click "Confirm" | Candidate is permanently removed from table and storage; total applicant count decreases by 1 | Pass |
| **TC-013** | Verify candidate cancellation on delete prompt | 1. Click delete (trash) icon on a candidate row<br>2. Click "Cancel" on confirmation prompt | Confirmation dialog closes and candidate record remains intact in candidate list | Pass |
| **TC-014** | Verify CSV export functionality | 1. Click CSV Export icon in top navbar<br>2. Verify browser download trigger and file content | CSV file named `talentflow_all_candidates.csv` downloads containing headers and comma-separated records | Pass |
| **TC-015** | Verify data persistence across browser refresh | 1. Add or edit a candidate<br>2. Refresh page using browser reload (F5)<br>3. Navigate to Candidates tab | Previously added/edited candidate data remains present, loaded from localStorage | Pass |
| **TC-016** | Verify dark and light theme toggle | 1. Click sun/moon theme toggle button in sidebar footer<br>2. Verify UI color scheme and contrast | Theme switches smoothly between dark (`data-theme="dark"`) and light (`data-theme="light"`), persisting in localStorage | Pass |
